# Ditt prosjekt i Klasserommet

Dette er din egen webside. Alt du lager her lagres automatisk.

- Editoren har en **læreassistent** — be den om hva som helst, for eksempel
  «lag en pen webside for å spille bondesjakk».
- Websiden din oppdaterer seg i det øyeblikket noe endres.
- Hovedfilen er `src/App.svelte`.

## Viktig

Dette repoet er **offentlig** — hele verden kan lese det. Skriv derfor
ALDRI inn passord, nøkler eller personlige opplysninger.
